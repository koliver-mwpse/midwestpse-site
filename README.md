# midwestpse.com

Static site for Midwest Public Safety Equipment, LLC. No build tools needed beyond Python 3.

- Edit content in `build.py`, then run `python3 build.py` to regenerate the `index.html` pages.
- Styles: `assets/site.css`; behavior (mobile menu, video embeds, quote form): `assets/site.js`.
- Preview locally: `python3 -m http.server 8090`.
